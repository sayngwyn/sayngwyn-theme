# Changelog

## 1.0.0

First release. A new dark theme for Mod Organizer 2 in sayngwyn's colours, written from scratch.

- Near-black surfaces, bone-white text, silver-outlined buttons; red only for selections and the Run button.
- A large Run button with the sayngwyn deer skull and "RUN" in Sayngwyn Serif on a dark red glow, level with a larger
  program picker.
- Selected rows get a bone outline as well as their fill, so they stay clear next to MO2's red conflict highlights.
- New line icons for the toolbar, list buttons, check boxes, radio buttons and arrows.
- Slim scrollbars, raised menus and tooltips, red selected tabs.
- Every text colour checked for 4.5:1 contrast on every background it can sit on.
